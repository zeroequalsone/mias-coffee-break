# Mias Coffee Break ☕

**Mia's Coffee Break** ist eine moderne, responsive Kaffee-Webseite auf Basis von Next.js (App Router). Die Seite präsentiert ein stilvolles Kaffee-Erlebnis mit ansprechenden Produktbereichen, Hero-Section, Slider und vollständig mobiloptimierter Navigation – perfekt für Kaffeeliebhaber und Genießer.

## Live Demo

Die aktuelle Deploy-Version ist hier erreichbar: `https://mias-coffee-break.vercel.app/`

Hinweis: Die Demo wird von **Vercel** nach einem erfolgreichen PR-Merge **zeitverzögert** aktualisiert und ist danach wieder **up to date** mit dem aktuellen Stand.
